Production Systems

Customer-service agent in production on a revenue-taking site

  • Answers customer questions from the business’s knowledge base and quotes from the price book by tool call. The model never states a price without a tool call.
  • Every reply and every tool result passes the same guards before the customer sees it. A reply that contains a price with no tool call behind it is stopped and handed to a person.
  • Human in the loop by design: the agent hands off on customer request, low confidence, repeated failure, frustration, prompt-injection flags, guard violation, undecided business policy or model error, and each handoff carries the transcript tail and the customer’s contact when given.
  • When a customer asks about a policy the business has not decided, the retrieval tool returns no answer and the case goes to a person. The rule is enforced in code, so the prompt cannot override it.
  • Next.js, TypeScript, Claude API, Stripe, Vercel. Built and run solo.
