Spend and efficiency

  • Set hard cost limits in production: an output-token cap, a chat-history cap (input tokens are billed), an 8-step limit per run, per-visitor and daily call limits, and a switch that keeps the agent off until it is turned on.
  • Use the cheapest path that passes its tests: a flat-rate subscription before metered API calls, local open models before frontier ones, and a stored answer with no model call when retrieval confidence is high.
  • Built an agent run budget that prices the next call before making it and stops the run at its cost or step ceiling, and an LLM gateway with cross-provider failover, circuit breakers, rate limits and an exact-match response cache.

Deciding what goes to an agent, to code, or to a person

  • Map each workflow with the people who run it, then decide which steps an agent takes, which steps code takes, and where a person approves.
  • Every agent hands off to a person with a reason code and the transcript. In evaluation, a correct handoff scores as a pass and an unneeded one as a miss.
  • The agent tells “the answer was not found” apart from “the business has not decided this,” so policy gaps go to the owner and are never guessed.

Measurement and governance

  • Release gates: a 103-scenario live evaluation with an answer-rate floor of 0.8 that is never lowered without a written reason, and a CI gate that fails the build when LLM or RAG output regresses and refuses to accept an empty baseline.
  • Decision-support tools leave the decision with a person: in my compliance tools, a model may add a reviewer note but cannot change a verdict.
  • Kept outputs of a model whose license excludes the United States out of every published or client-facing work product.
  • Check every public claim against the code before it ships, and remove any claim that no measurement supports.

Running AI agents as a team

  • Direct up to 17 concurrent AI agent sessions with shared written rules, a memory system, review hooks, and a gate that checks every paid generation job against an approved tool list before it runs.
